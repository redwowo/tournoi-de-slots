✓ Compteur dynamique du nombre de sélections
✓ Surlignage des lignes sélectionnées

✓ Bouton "Exporter les sélectionnés" (désactivé si aucune sélection)

🧪 Logique implémentée

✓ Maintien de l'état des sélections en mémoire
✓ Conservation des sélections lors des filtres/recherches
✓ Gestion automatique du checkbox "sélectionner tout"
✓ État indeterminate quand une partie des éléments est sélectionnée
✓ Confirmation avant suppression en masse
✓ Export JSON des tournois sélectionnés
✓ Historique des actions en masse

📁 Fichiers modifiés

admin-panel.html: Ajout de la colonne checkbox et des boutons d'action
admin-manager.js: Logique de sélection multiple et actions en masse
admin-styles.css: Styles pour checkboxes, surlignage et responsive
admin-panel.js: Intégration de la sélection dans le rendu du tableau

🎯 Instructions de test

1. Accéder au panneau admin : http://localhost:3000/admin-panel.html
2. S'authentifier avec le code admin
3. Aller dans la section "Tous les Tournois"
4. Tester la sélection individuelle des tournois
5. Tester le bouton "Sélectionner tout"
6. Tester les filtres et vérifier que les sélections sont conservées
7. Tester l'export des sélections
8. Tester la suppression en masse (avec confirmation)

⚠️ Points d'attention

• Les sélections sont conservées lors du filtrage mais seulement pour les éléments visibles
• L'état "indeterminate" du checkbox s'active quand une partie seulement est sélectionnée
• Les actions en masse sont désactivées si aucune sélection
• Le design est responsive et fonctionne sur mobile
